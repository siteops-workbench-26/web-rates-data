# Public mortgage-rate data — staging

This repository is **public** and is intended to hold only a small feed of mortgage rates already published by MortgageWebCenter, plus the automation code needed to retrieve them. It must not contain member information, internal spreadsheets, passwords, tokens, or private documents.

This is not a production-approved financial rate service. The published feed is checked against basic validation and time limits; product interpretation, advertising disclosures, hosting suitability and site QA remain subject to ACU review.

The associated internal calculation tests and Chad's original workbook remain outside this public repository.
